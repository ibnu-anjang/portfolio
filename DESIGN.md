# DESIGN.md - Design Direction for Ibnu Anjang Portfolio

## Identity & Personality
- Developer: Ibnu Anjang
- Role: Mobile & Backend Developer (Flutter, Python / FastAPI, System Security)
- Personality: Craft-oriented, practical, security-conscious, grounded (evidence over hype)

## Palette
- Base Background: Deep Obsidian `#0b080c`
- Elevated Surface: Dark Tint `#120e18`, Cards `#16121d` / `rgba(255, 255, 255, 0.03)`
- Borders: `rgba(255, 255, 255, 0.08)`
- Primary Accent: Soft Violet `#a87cff` / `#c2a4ff`
- Contrast Text: White `#ffffff`, High-contrast Zinc `#eae5ec` / `#d4d4d8`
- Muted Text: WCAG AA compliant Zinc `#a1a1aa` (4.5:1+ against dark background)
- Status Positive: Emerald `#34d399`

## Typography
- Headings & Body: Geist Sans (clean, technical, readable)
- Code & Tech Specs: Geist Mono (structured data, parameters, config)

## Antislop Dials
- Dial: ENERGY 2 / RHYTHM 2 / MOTION 2
- Tone: No em dashes (R-02), no buzzwords (R-16), authentic evidence from GitHub repositories (R-17, R-38).
